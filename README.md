# Brain_training_frontend

두뇌 성장 교실의 **Java Swing 데스크톱 프론트엔드** 시작 프로젝트.
추가 라이브러리 없이 JDK 21로 빌드한다. 웹 서버·Node.js는 필요하지 않다.

## 시작

JDK 21의 `bin`이 PATH에 있어야 한다. GUI 실행에는 데스크톱 디스플레이가 필요하다.

```sh
bash scripts/build.sh
bash scripts/check.sh
bash scripts/run.sh
```

`build/`는 생성 결과이며 Git에서 제외된다. 스크립트는 어느 디렉터리에서도 실행할 수 있다.

## 현재 범위

실행하면 다음 순서로 진행한다.

1. 이름 또는 별명(1~20자), 만 나이(6~13세), 성별(선택 안 함 가능).
2. 곰·토끼·고양이·여우 중 아바타 선택.
3. 인지 6분야의 시작 테스트: 분야별 3문항, 총 18문항.
4. 분야별 정답률의 육각형 그래프와 이번 풀이의 강점·연습할 부분 안내.
5. 선택한 아바타·이름, 동일 결과 그래프, 학습 6분야 카드가 있는 메인 화면.

시작 테스트는 실제 답안을 판정하는 로컬 간이 버전이다. 숫자 조합, 관계 추론,
도형 회전, 숫자 기억, 목표 탐색, 규칙 전환을 객관식으로 제공한다.
응답은 무제한이며 기억력은 3초간 숫자를 보여준 다음 숨긴다.
정식 측정 게임 6종과 훈련 게임 6종 전체가 구현된 것은 아니다.
메인 화면의 훈련 게임 실행 버튼은 아직 비활성화 상태다.

프로필과 결과는 **이번 실행 메모리에만 유지**된다. 파일 저장·계정·재실행 복원은 미구현이다.
성별·나이는 점수 보정이나 추천에 사용하지 않는다.

그래프는 각 분야의 `정답 수 / 3 × 100`으로, 표준화 점수나 IQ가 아니다.
2문제 이상 맞힌 분야는 격려하고 나머지는 연습을 안내하는 시작용 문구이며,
영역 간 점수 순위·취약 인지능력 진단·자동 추천 정책으로 사용하지 않는다.
정식 백엔드 시간·난이도·점수·저장 정책은 후속 계약 검토 대상이다.

`bash scripts/check.sh`는 기존 메인 UI, 시작 서비스, 전체 온보딩 UI를 검증한다.
현재 실행의 화면 이미지는 `build/onboarding-profile.png`, `onboarding-avatar.png`,
`onboarding-test.png`, `onboarding-memory.png`, `onboarding-result.png`,
`onboarding-home.png`에 생성한다. 화면 샘플은 가상 프로필이다.
headless 렌더링 검증과 실제 데스크톱 창의 수동 검증은 구분한다.

## 구조

- `src/brainclassroom/frontend/`: 실행 진입점·UI
- `src/brainclassroom/onboarding/`: 시작용 로컬 프로필·테스트·결과 서비스
- `checks/brainclassroom/`: 외부 테스트 라이브러리 없는 서비스·화면 검증
- `docs/UPSTREAM_RULES.md`: 원본 규칙 출처·적용·미확정 계약
- `AGENTS.md`: 후속 개발 작업 규칙

다음 단계는 첫 측정·훈련 게임 한 쌍과 화면 데이터·입력·오류·상태 전환을 백엔드 담당자와 맞추는 것이다.
